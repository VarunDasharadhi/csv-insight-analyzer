# Agent instructions

Streamlit web app that takes an uploaded CSV and returns column types, missing values, numeric/categorical stats, charts, and a PDF report.
Stack: Python, Streamlit, pandas, matplotlib, seaborn.
Run locally: pip install -r requirements.txt, then streamlit run app.py.
Status: shipped, live at https://csv-insight-analyzer.onrender.com, dormant since 2026-06-11 (no code changes since).
Nothing unusual.
